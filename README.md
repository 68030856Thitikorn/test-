# โครงงานวิเคราะห์ข้อมูลด้วย Python: ชุดข้อมูล Advertising

วิเคราะห์ความสัมพันธ์ระหว่างงบโฆษณาผ่านสื่อ 3 ช่องทาง (TV, Radio, Newspaper) กับยอดขาย (Sales) ด้วยสถิติเชิงพรรณนา การตรวจหาค่าผิดปกติ การสร้างกราฟ ค่าสหสัมพันธ์ และโมเดล Linear Regression แบบแบ่งข้อมูล Train/Test

## ชุดข้อมูล

ไฟล์ `Advertising.csv` มี 200 แถว (200 ตลาด) ไม่มีค่าสูญหายและไม่มีแถวซ้ำ

| ตัวแปร | ความหมาย | บทบาท |
|---|---|---|
| TV | งบโฆษณาทางโทรทัศน์ | ตัวแปรต้น |
| Radio | งบโฆษณาทางวิทยุ | ตัวแปรต้น |
| Newspaper | งบโฆษณาทางหนังสือพิมพ์ | ตัวแปรต้น |
| Sales | ยอดขาย | ตัวแปรตาม |

หมายเหตุ: ไฟล์มีคอลัมน์ `Unnamed: 0` ซึ่งเป็นเลขลำดับ โค้ดจะตัดทิ้งก่อนวิเคราะห์

แหล่งที่มา: _(ใส่ลิงก์ Kaggle ของชุดข้อมูล)_

## สิ่งที่วิเคราะห์

1. ตรวจสอบข้อมูลเบื้องต้น (ขนาด ชนิดข้อมูล ค่าสูญหาย แถวซ้ำ)
2. สถิติเชิงพรรณนา: ค่าเฉลี่ย ส่วนเบี่ยงเบนมาตรฐาน (ddof=1) ต่ำสุด มัธยฐาน สูงสุด
3. ตรวจหาค่าผิดปกติด้วยกฎ 1.5 × IQR
4. กราฟ: ฮิสโตแกรม แผนภาพกล่อง และกราฟการกระจายระหว่างงบโฆษณากับ Sales
5. ค่าสหสัมพันธ์ระหว่างตัวแปร
6. แบ่งข้อมูล Train/Test (80/20, `random_state=42`) แล้วสร้างโมเดล Linear Regression ทำนาย Sales จาก TV, Radio, Newspaper วัดผลด้วย R², RMSE, MAE

## ผลเบื้องต้น

**สถิติเชิงพรรณนา**

| ตัวแปร | ค่าเฉลี่ย | ส.บ.ม. |
|---|---|---|
| TV | 147.04 | 85.85 |
| Radio | 23.26 | 14.85 |
| Newspaper | 30.55 | 21.78 |
| Sales | 14.02 | 5.22 |

**ความสัมพันธ์กับ Sales:** TV 0.782, Radio 0.576, Newspaper 0.228 พบค่าผิดปกติเฉพาะ Newspaper จำนวน 2 ค่า

**โมเดล Linear Regression** (train 160 แถว, test 40 แถว)

| ชุดข้อมูล | R² | RMSE | MAE |
|---|---|---|---|
| Train | 0.8957 | 1.6447 | 1.1985 |
| Test | 0.8994 | 1.7816 | 1.4608 |

R² ของ train และ test ใกล้เคียงกัน แสดงว่าโมเดลไม่ได้จำข้อมูลสอนมากเกินไป สัมประสิทธิ์ของ Radio (0.1892) สูงสุด ส่วน Newspaper (0.0028) แทบเป็นศูนย์
